# 🚀 Harshawardhan Shrivastava — Developer Portfolio

**Live Web Application**: Built for recruiters, founders, and engineering managers evaluating AI systems engineering and full-stack software capabilities.

## 🌟 Highlights Included:
- **Image-Free & Ultra-Professional**: Modern high-contrast dark aesthetic with glassmorphism, responsive grids, and typography.
- **Production Systems**:
  - **miniVoxSetu**: Voice AI Banking Agent (`minivoxsetu.bugbiceps.in`)
  - **GitHub Analyzer**: MCP Server & Code Reviewer (`githubAnalyser.bugbiceps.in`)
  - **HireReady**: Multi-Modal Placement Engine (`hireready.bugbiceps.in`)
- **Interactive Contact**: 1-click email copy, collaboration mailto composer, and direct PDF resume downloads.

## 📦 Instant Deployment
This portfolio is pure, static, ultra-fast HTML5/CSS3/JS. It can be deployed in 30 seconds to:
- **Vercel**: Import this folder directly.
- **GitHub Pages**: Push to a repository and enable Pages under Settings.
- **Netlify / Render Static Site**: Connect and deploy instantly.
